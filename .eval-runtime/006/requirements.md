# Requirements

## Functional Requirements
- FR-001 — Trainers can define available appointment slots.
- FR-002 — Clients can view available slots for a trainer.
- FR-003 — Clients can book one available slot.
- FR-004 — Trainers can view upcoming bookings.
- FR-005 — A booked slot must no longer appear as available to another client.
- FR-006 — Clients can cancel a booking up to 24 hours before the appointment.

## Constraints
- The first release should remain simple enough for a small pilot group.
- No specific implementation technology has been selected.

## Open Questions
- OQ-001 — Notification channel is not yet decided.
- OQ-002 — Reporting/analytics beyond upcoming bookings is not yet decided.
