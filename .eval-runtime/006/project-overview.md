# Project Overview

## Goal
Create a simple appointment-booking service for independent personal trainers so clients can book available sessions without manual scheduling coordination.

## Users
- Trainer — publishes availability and manages bookings.
- Client — views availability and books a slot.

## Scope
- Publish appointment availability.
- View trainer availability.
- Book one available slot.
- View upcoming trainer bookings.
- Prevent double booking.
- Allow cancellation up to 24 hours before the appointment.

## Non-goals
- Online payments.
- Multi-trainer organizations.
- Membership subscriptions.
- Automated marketing campaigns.

## Success criteria
- A trainer can publish availability and receive a valid booking without manual scheduling coordination.
- Two clients cannot successfully book the same slot.

## Open items
- Notification channel is not yet decided.
- Reporting/analytics beyond upcoming bookings is not yet decided.
